# AI-Powered Startup MVP Builder

## Overview
A lean startup sprint project designed to define, architect, implement, test, and deploy a Minimum Viable Product (MVP) using modern AI-assisted software engineering practices.

## Project Contents
- [`mvp_concept.md`](./mvp_concept.md): MVP concept definition for EcoRide, specifying the core problem statement, target user personas, 3–5 foundational features, and technical/business constraints.
- [`user_stories.md`](./user_stories.md): 10 prioritized user stories with acceptance criteria covering authentication, ride publishing, discovery, atomic seat reservation, cancellation, cost-share calculation, and dashboard management.
- [`architecture.md`](./architecture.md): 3-tier client-server architecture specification featuring component breakdowns, a Mermaid system diagram, and an end-to-end booking transaction sequence diagram.
- [`data_model.md`](./data_model.md): Relational data model schema specification with 4 entities (`users`, `rides`, `bookings`, `reviews`), a Mermaid ER diagram, integrity constraints, and indexing strategy.
