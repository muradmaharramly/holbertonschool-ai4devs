# Copilot Productivity Sprint

## Overview
Controlled benchmarking sprint comparing manual software development against AI-assisted development using GitHub Copilot across defined programming tasks, metrics, and structured reflection.

## Contents
- [`setup_notes.md`](./setup_notes.md): Verified IDE, AI assistant, runtime, and extension versions, plus isolation settings for manual vs. Copilot-assisted sprint runs.
- [`benchmark_tasks.md`](./benchmark_tasks.md): Three scoped 15–30 minute benchmark tasks with requirements, inputs, outputs, and acceptance criteria.
