# Prompt Patterns Library

## Overview
A categorized library of reusable prompt patterns and structured use cases designed to enhance developer productivity, reliability, and code quality in AI-assisted workflows.

- [`prompts/`](./prompts/): Reusable prompt templates featuring defined roles, task descriptions, input placeholders, and expected output formats.

  - [`style_enforcement.md`](./prompts/style_enforcement.md): Coding style and formatting enforcement.
  - [`code_smell_detection.md`](./prompts/code_smell_detection.md): Static code smell and anti-pattern inspection.

  - [`edge_case_analysis.md`](./prompts/edge_case_analysis.md): Boundary condition and edge case discovery.
  - [`resource_leak_investigation.md`](./prompts/resource_leak_investigation.md): Memory, connection, and handle leak diagnosis.
  - [`api_docstring_generation.md`](./prompts/api_docstring_generation.md): API documentation and standardized docstring generation.
  - [`architecture_overview.md`](./prompts/architecture_overview.md): Technical architecture and module contract documentation.

  - [`unit_test_generation.md`](./prompts/unit_test_generation.md): Unit test suite generation and branch coverage.
