# holbertonschool-ai4devs

## Overview
This repository contains projects and practical exercises developed for the Holberton School **AI for Developers** (ai4devs) curriculum.

## Projects

| Directory | Description |
| :--- | :--- |
| [`prompt_patterns_library`](./prompt_patterns_library) | Reusable prompt patterns, use cases, templates, and evaluation benchmarks for AI-assisted engineering workflows. |
| [`prompting_debug_assistant`](./prompting_debug_assistant) | Flawed code snippets, debugging workflows, and structured root-cause analysis with AI assistants. |
| [`ai_specification_writer`](./ai_specification_writer) | Structured product and technical specification package for CarpoolConnect, created through AI-assisted specification workflows. |
| [`copilot_productivity_sprint`](./copilot_productivity_sprint) | Controlled manual vs. GitHub Copilot coding productivity sprint, environment setup, metrics, and reflection. |
| [`ai_powered_startup_mvp_builder`](./ai_powered_startup_mvp_builder) | Lean startup MVP sprint simulating end-to-end MVP specification, architecture, implementation, and deployment with AI assistance. |
| [`ai_code_review_simulator`](./ai_code_review_simulator) | Pull request simulation, task filtering feature, AI code review workflows, and comparative evaluation. |
| [`smart_bug_bounty`](./smart_bug_bounty) | AI-assisted bug bounty challenge investigating flawed code snippets, root-cause analysis, and verified remediation. |
| [`ai_enhanced_team_hackathon`](./ai_enhanced_team_hackathon) | Collaborative 24-hour AI-accelerated hackathon simulation covering ideation, MVP scoping, rapid delivery, and team reflection. |
